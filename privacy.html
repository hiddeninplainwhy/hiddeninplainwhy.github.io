Privacy policy

Effective October 22, 2026.

Hidden in Plain Why Publisher is operated for the Hidden in Plain Why brand. This policy describes its use of connected-platform data and this public information website.

Data used by the publisher

The publisher uses OAuth client credentials and authorization tokens, the connected Facebook Page and Instagram account identifiers, account names and their link, and videos and posting metadata supplied by the brand operator. It stores job status, upload identifiers, scheduling information and provider error summaries needed to operate and troubleshoot publishing. The YouTube permission is for uploading videos. The publisher does not request access to Gmail messages or social account passwords.

Purpose and sharing

Data is used to authenticate the brand's approved accounts, upload and schedule approved videos, check publishing status and prevent duplicate attempts. Videos and captions are transmitted to the selected social platforms. Credentials are stored locally with Windows user encryption and, when cloud hosting is configured, in the private repository's encrypted GitHub Actions secrets. GitHub runs the worker and hosts private source code and publishing receipts. The app does not sell connected-platform data or use it for advertising profiles or AI model training.

The application's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements. This publisher uses YouTube API Services; Google's handling of data is described in the Google Privacy Policy. Meta and GitHub also process information according to their own applicable policies.

Storage and retention

Credentials are retained while the connection is used, until revoked, replaced or removed by the operator. Queue metadata, copied videos and job receipts remain until the operator removes them. Receipts saved in Git history may remain in repository history after file changes. No fixed automatic deletion schedule has been implemented. Access is limited to the operator and the hosting/platform systems used for publishing.

Revoking access and deletion

The operator can revoke Google's access at Google account permissions, remove the Meta business integration through Facebook settings, remove the GitHub Actions secret and stop the workflows. Revocation does not automatically delete copies of videos already uploaded to a platform. Uploaded posts can be managed on that platform. Requests to remove publisher-held data can be sent to hiddeninplainwhy@gmail.com.

This website

This static information site has no account registration, forms or app analytics scripts. Its hosting provider, GitHub Pages, may process ordinary request information such as IP address and browser details to serve and secure the site. See the GitHub Privacy Statement.

Changes and contact

Updates will appear on this page with a revised effective date. Contact: hiddeninplainwhy@gmail.com.
